# ASAN suppression rules for appium tests that use PySide6.
#
# PySide6 allocates Qt objects using Python's allocator but frees them with
# C++ delete. ASAN intercepts delete and reports a bad-free error when the
# memory was not allocated with malloc. This is a false positive in the context
# of PySide6, as the memory is managed by Python's garbage collector.
#
# Reference: https://bugs.kde.org/show_bug.cgi?id=501991

# QPanGesture::~QPanGesture() bad-free triggered via QTextEdit construction in PySide6.
# "bad-free" errors are suppressed via the alloc_dealloc_mismatch type.
alloc_dealloc_mismatch:QPanGesture
